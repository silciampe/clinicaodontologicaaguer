# Design System

## Concepto Visual

La identidad visual debe inspirarse en clínicas médicas premium europeas y estudios profesionales contemporáneos.

No utilizar recursos visuales excesivamente comerciales ni elementos gráficos infantiles.

La experiencia debe sentirse:

* Serena
* Profesional
* Moderna
* Humana
